## Pourquoi ce gel

Audit marché + concurrence (16/08/2026) :

1. **La couche agentique WordPress existe déjà** : AI Engine (MCP), Agent Builder
   (agents illimités + 250 outils GRATUITS), Frontman (agent éditeur de site).
2. **Les géants dominent** : Jetpack AI (Automattic), Elementor AI, Rank Math/AIOSEO —
   équipes + budgets que nous n'avons pas.
3. **Laravel AI** (officiel, v0.7.0 mai 2026) couvre "le framework PHP IA" mieux que nous.
4. **WordPress 7.0** (mai 2026) a intégré l'IA native (AI Client, Connectors, MCP Adapter) —
   une partie de notre proposition est commoditisée dans le core.

**Verdict** : la course "SDK/plugin IA WordPress" est perdue d'avance en l'état.
Le vrai modèle viable est le SERVICE d'agents IA (1 profil Hermes isolé/client, ~497€/mois),
pas la vente d'un SDK. Le SDK reste un outil interne + vitrine.
